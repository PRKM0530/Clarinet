What Clarinet collects
Clarinet watches the network it is installed on. This page lists exactly what it records and for how long.

What it records

  • Devices: the hardware address (MAC), network address (IP), device name, maker and when each device was last seen.
  • How much data each device uses: bytes downloaded and uploaded, per device, per hour.
  • Website names: only the main domain a device looks up, such as youtube.com. Clarinet uses these to say whether an hour was mostly streaming, browsing, gaming and so on. It does not keep the full address, the page, or anything you typed.
  • Connection quality: speed test results and how quickly the router and the internet respond.
  • Security observations: nearby Wi-Fi network names, the router's settings checks, and the networks this server has connected to.
  • Accounts and actions: usernames, scrambled (hashed) passwords, login attempts, and a log of what administrators change.

What it does not record

  • The content of your traffic: no messages, pages, passwords or files.
  • Which pages you read, what you searched for, or what you did on a website. Clarinet only sees the domain name a device asked for.

How long it is kept

  • Hourly usage per device: {{ traffic_days }} days, then deleted automatically.
  • Website names: {{ domain_days }} days. After that only the totals for each type of activity are kept.
  • Short-term traffic samples: {{ sample_hours }} hours.
  • Login attempts: {{ login_days }} days.
  • Everything else stays until an administrator deletes it (Settings, Delete stored data).

Where it goes

Nothing leaves your network. Clarinet runs on your own hardware and has no cloud account and no tracking. The only outside contact is the speed test and the checks of public servers that measure response time; neither carries any information about you or your devices.

The person who runs this Clarinet is responsible for telling the people on the network that it is in use.
